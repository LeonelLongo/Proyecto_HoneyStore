## Qué incluye

- Sitio responsive de 4 páginas: Inicio, Productos, Nosotros y Contacto.
- Modo oscuro que recuerda la preferencia del usuario (`localStorage`).
- Formulario de contacto con validación en tiempo real para realizar pedidos.
- Animaciones con CSS.
- Diseño inspirado en un panal: amarillos, dorados y marrones.

No incluye carrito de compras: los pedidos se hacen desde la sección de contacto.
